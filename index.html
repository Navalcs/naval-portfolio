About me

I completed my B.Sc in Computer Science and I'm now a first-year M.Sc IT (Cloud Computing) student. My curiosity started with a simple question: where does an app actually live once you close it? Chasing that answer led me from writing Python scripts to launching my first EC2 instance.

My full focus is cloud services. I'm learning to master the IaaS, PaaS and SaaS models, migrating on-premises systems to the cloud, and managing client services on AWS. My goal is to become a cloud solutions architect who helps businesses run reliably in the cloud.

NavalDS: data structures visualizer

This was my first project, built during my B.Sc in Computer Science. It is a web platform with 11 data structure and algorithm modules, including linked lists, stacks, queues, binary trees, graphs and hash tables. I implemented insertion, deletion, traversal, DFS, BFS and Huffman encoding and decoding, and used object-oriented programming with interactive visualizations to show how each operation works. It also includes a permutation-based solution to the Travelling Salesman Problem that finds the shortest route.
